04 / SPECIFICATIONS

Engineered for speed, density, and precision.

Real production capabilities designed around modern browser standards without framework overhead.

GitHub REST API v3

Direct HTTP communication with GitHub's public API endpoints, respecting rate headers and response boundaries.

RFC 5988 Link Pagination

Automatically iterates multi-page repository collections (100 items/page, capped at 2,000) via standard Link headers.

Pure In-Memory Analyzer

Separation of concerns: all statistical computations, frequency counts, and sorting logic live as pure functions in analyzer.js.

Instant Filter & Sort

Client-side repository search across names and descriptions, plus multi-criteria sorting (Stars, Forks, Recently Updated, Name).

Responsive Chart.js Graphics

Accessible doughnut chart with authentic GitHub language colors, percentage computation, and responsive legend stacking.

Rolling Push Telemetry

Measures actual push cadence across Today, 7-Day, and 30-Day rolling windows based on raw repository pushed_at timestamps.

Deep-Linking & Keyboard Access

Shareable query parameter ?u=username, one-click link copying, and global / shortcut for rapid keyboard focus.

Typed Error Boundaries

Structured ApiError hierarchy handling missing profiles (404), rate limit resets, and network failures with informative feedback.

05 / ARCHITECTURE

Zero framework bloat. Pure client-side pipeline.

RepoLens is architected as a modular, high-performance vanilla JavaScript application using standard browser APIs.
